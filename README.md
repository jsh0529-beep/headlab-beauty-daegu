# HEAD LAB 평생교육원 · 미담장 대구

생활미용과 두피·모발 전문교육을 소개하는 한국어 홍보 웹페이지입니다.

정적 HTML/CSS 사이트이며 `index.html`을 GitHub Pages로 게시할 수 있습니다. 별도 빌드가 필요하지 않습니다.

## 구성

- 표지 및 교육원·대표 소개
- 생활미용·취미 및 전문교육 과정
- 평생교육이용권 안내와 결제 예시
- 수강신청 절차, 공식 안내 QR, 전화문의
- 모바일 반응형 레이아웃

## 이미지와 안내

수업 이미지는 AI 생성 예시입니다. 대표 사진은 미담장 공식 홈페이지(https://midamjang.co.kr/greeting)에서 가져왔습니다.

민간자격별 등록번호, 발급기관, 비용, 환불규정은 확인 후 추가해야 합니다. 수업 일정, 이용권 사용 가능 강좌와 지원 조건은 교육원 및 해당 사업 공고를 확인해 주세요.
